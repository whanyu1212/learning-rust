# Cargo Basics

> **TL;DR** — `cargo new` scaffolds a package *and* its directory; `cargo init` fills a directory you already have. Same flags, same output.

Cargo is the package manager, build tool, and test runner. These three pages cover the only commands you need to get a crate on disk.

- [cargo init](./cargo-init.md) — turn the current directory into a package.
- [cargo new](./cargo-new.md) — create a directory and a package in one step.
- [Init vs New](./cargo-comparison.md) — side-by-side, plus the shared flag reference.

Default to `new` unless you already have a folder.
