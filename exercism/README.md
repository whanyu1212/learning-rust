# Exercism (Rust)

Local copies of the [Rust track](https://exercism.org/tracks/rust) exercises.

- Layout: `rust/<exercise-slug>/` (required by the Exercism CLI)
- Attempted vs not: [STATUS.md](./STATUS.md)
- Track order: [LEARNING_PATH.md](./LEARNING_PATH.md)
- Tests: `cd rust/<slug> && cargo test`
- Submit: `cd rust/<slug> && exercism submit`

This folder is the Exercism workspace (`exercism configure --workspace`).
GitHub Pages / mdBook do not include these files.
